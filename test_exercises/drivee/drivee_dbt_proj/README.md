# 🚕 Анализ данных сервиса "Super Easy Ride 3000" (Night City)

Решение тестового задания на позицию **BI-разработчика**. В рамках проекта проведен полный цикл: от обработки сырых данных до построения аналитического дашборда.

---

## 🎯 Цель проекта
Предоставить сотрудникам отдела развития бизнеса (Business Development) удобный инструмент для мониторинга ключевых показателей сервиса такси в Night City за октябрь 2077 года и принятия управленческих решений.

---

## 🏗 Архитектура и стек технологий
Для реализации выбран современный стек инструментов, обеспечивающий высокую скорость обработки данных (MDS - Modern Data Stack):

* **Storage:** `DuckDB` — высокопроизводительная аналитическая БД для обработки данных.
* **Transformation:** `dbt` (data build tool) — для структурирования логики, очистки данных и создания витрин.
* **BI Layer:** `Apache Superset` — для визуализации и построения интерактивного дашборда.

---

## 🛠 Подготовка данных и качество (Data Quality)
В процессе исследования данных (EDA) были проведены следующие мероприятия по очистке:

1.  **Дедупликация:** Был сформирован уникальный ключ на основе полей `vendor_name`, `pickup_datetime`, `dropoff_datetime`, `pickup_location_id`, `dropoff_location_id` и `total_amount`. Выявлено и удалено **4 полных дубликата**.
2.  **Фильтрация по периоду:** В соответствии с техническим заданием (октябрь 2077), из финального отчета исключены записи, не попадающие в указанный временной интервал.
